cct

Claude Code TUI Launcher —— 多配置一键启动的终端启动器

内部分享 · 背景 / 问题 / 用法 / 设计

Rust · ratatui · 单二进制 · MIT

01背景

  • 团队日常使用 Claude Code 作为 AI 编程助手
  • 实际使用中往往存在多套接入配置：官方 API、第三方中转、不同模型、不同权限模式
  • Claude Code 的配置几乎完全靠环境变量驱动： ANTHROPIC_BASE_URL / ANTHROPIC_API_KEY / ANTHROPIC_MODEL …
  • 再叠加 CLI flags（--model、--dangerously-skip-permissions、--continue），组合非常多

02要解决的问题

切换配置成本高

换一套接入 = 手工 export 一连串环境变量，容易串号、漏设、残留

配置散落难管理

API Key 散落在 shell rc、临时脚本、历史命令里，既难维护也容易泄露

常用操作要记 flag

跳过权限、恢复上次会话、换模型…… 每次都要翻文档拼参数

团队没有统一入口

新人上手靠口口相传，配置格式五花八门

03cct 是什么

  • 一个 Rust 单二进制 终端 UI 启动器（ratatui + crossterm）
  • 所有接入配置收进一个 TOML 文件，称为 profile（名称 + 模型 + env + flags）
  • 打开 TUI → 上下键选 profile → 回车即启动 Claude Code
  • 启动采用 Unix exec() 进程替换：cct 完全退出，零包装、零开销，终端干净继承
  • 同时提供 CLI 子命令：cct add / cct run / cct env / cct edit
profiles.toml→ cct TUI→ exec→ claude

注：本次分享聚焦 Claude Code 后端；Codex / Kimi 后端开发中，后续将支持按 Tab 切换多后端。

04用法 · TUI 主界面

运行 cct 进入界面：左侧 profile 列表 + 右侧详情面板（敏感值自动打码）：

$ cct

 ┌ Claude ────────────────────────────┐
 │ ▸ third-party    kimi-k2           │
 │   official       claude-sonnet-4   │
 │   staging        (red: skip-perms) │
 └────────────────────────────────────┘
按键作用
j / k上下选择 profile
Enter启动选中 profile
c带 --continue 启动，恢复上次会话
s切换 skip_permissions（立即落盘，行变红）
t切换 API_KEY / AUTH_TOKEN 认证方式
a / e / d新增 / 编辑 / 复制 profile（内联表单）
q退出

05用法 · CLI 子命令

$ cct add                    # 交互式新增 profile（5 个提示，自动补全 env）
$ cct add --auth-type token # 写入 ANTHROPIC_AUTH_TOKEN 而非 API_KEY

$ cct run third-party       # 不进 TUI，按名字直接启动
$ cct run                   # 数字选择器

$ cct env                   # 非交互列出所有 profile
$ cct env my-profile -- claude --model haiku --verbose
                              # 注入该 profile 的环境，运行任意命令
$ cct edit                  # 用 $EDITOR 直接打开 profiles.toml

cct env 背后的 Unix 哲学

"做一件事，把它做好；程序要能与未知程序组合。" —— cct env 只做"注入环境再执行"这一件事：它不认识 claude 的任何 flag，claude 也不认识 cct，二者仅靠环境变量和标准进程语义组合。因此任何现有或将来的 CLI（不限于 claude）都能零适配地被 cct 接管环境。

06配置 · 一个 TOML 文件

macOS：~/Library/Application Support/cc-tui/profiles.toml · Linux：~/.config/cc-tui/profiles.toml

[[profiles]]
name = "third-party"
description = "Third-party Claude endpoint"
model = "kimi-k2"            # → --model
skip_permissions = false     # → --dangerously-skip-permissions
auth_type = "token"          # 可选：用 ANTHROPIC_AUTH_TOKEN
extra_args = ["--verbose"]   # 原样追加

[profiles.env]                # cct add 自动生成
ANTHROPIC_BASE_URL = "https://api.example.com/v1"
ANTHROPIC_API_KEY = "sk-..."
ANTHROPIC_MODEL = "kimi-k2"
ANTHROPIC_DEFAULT_SONNET_MODEL = "kimi-k2"
API_TIMEOUT_MS = "600000"
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC = "1"

✓ 结论：所有接入配置收敛在这一个文件里 —— 拷走这一个文件，就迁移了全部配置（换机器、共享给同事均适用）。

07设计 · 架构（5 个模块，无共享状态）

模块职责
configTOML 解析与校验；profile 追加/更新；toggle 用 toml_edit 外科手术式改写（保留注释）
app光标状态、Normal/AddForm 模式、FormState 字段映射的单一事实源
uiratatui 渲染：列表 + 详情 35/65 分栏、表单、敏感值打码
launch构建参数（--model / skip-perms / extra_args）、注入 env、exec() 进程替换
clicct add 交互流、cct run 选择器、cct env 注入执行

数据流单向：config → app → ui → launch，无循环依赖，更接近 Unix filter 而非服务程序。

08设计 · 关键决策

exec 而非 spawn

进程替换启动 claude，无父进程驻留，终端行为与原生完全一致

toml_edit 外科改写

按 s / t 切换配置时只改一个键，注释和顺序原样保留

秘密值全路径打码

任何含 TOKEN / KEY / SECRET 的 env，在 UI、确认摘要中一律掩码

防御性默认注入

每个 Claude profile 启动前自动注入隐私默认值（关闭自动更新、遥测 opt-out 等）

单一事实源

表单字段 → profile 的映射集中在 FormState::to_new_profile()，杜绝字段错位

配置热重载

e 键打开编辑器，保存后不重启进程直接重新解析

09工程质量

  • 单元测试：配置解析、参数构建、打码、toggle 逻辑（模块内 #[cfg(test)]）
  • 集成测试（mock）：用假 claude 脚本 stub 外部命令，断言捕获到的参数（tests/integration.rs）
  • 集成测试（live）：CCT_LIVE_TESTS=1 走真实 claude 二进制
  • BATS shell 测试：install.sh 用 export -f stub 隔离测试
  • CI：push/PR 跑 clippy + test，打 tag 自动发 release 二进制（Linux x86_64/aarch64、macOS arm64/x86_64）
cargo test                    # 全部测试
cargo test --test integration # E2E (mock)
bats tests/install.bats       # 安装脚本测试

10安装与上手

内网（self-hosted GitLab）一键安装到 ~/.local/bin/cct：

curl -fsSL https://gitlab.clounix.com/zhengjy/cc_starter/-/raw/master/install.sh | \
  GITLAB_URL=https://gitlab.clounix.com GITLAB_PROJECT=zhengjy/cc_starter bash

或从源码安装（需 Rust 1.70+）：

cargo install --path .

上手三步：

  • 运行一次 cct，自动生成默认配置文件
  • cct add（或 TUI 里按 a）添加你的接入配置
  • cct → 选择 → 回车，开始干活

若本机未装 claude，cct 启动时会提示并可直接执行官方安装脚本。

11总结

  • 一个文件收敛所有 Claude Code 接入配置，告别手工 export
  • 一次回车完成启动：exec 进程替换，零开销、终端干净
  • 一组按键覆盖日常操作：切权限、切认证、续会话、增删改 profile
  • 一套纪律保证质量：秘密打码、防御性默认值、toml_edit 保注释、多层测试
